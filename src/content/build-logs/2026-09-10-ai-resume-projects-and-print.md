## 背景

本次调整的目标不是简单增加简历篇幅，而是把两年多制造业信息化经历整理成招聘人员容易阅读、面试时能够继续展开的项目证据。项目描述统一突出业务场景、技术方案、关键难点和个人职责。

## 项目经历调整

简历项目经历由单段简介升级为“项目名称 + 技术栈 + 多条职责亮点”，当前包括：

1. A 股智能分析与问股 Agent；
2. MES 智造云 Web 工作台与应用中心；
3. MES 积木报表集成与低代码报表平台；
4. 大马力 MES 桌面端 Shell 与双模式导航重构；
5. EAM 资产管理系统 Web / API / App 多端迭代。

其中积木报表项目来自本人在 2026 年 8 月 20 日至 21 日的真实提交。实现范围覆盖 JimuReport 1.8.0 与 Java 8 / Spring Boot 2 的版本适配、11 张必要元数据表初始化、MES Token 与多租户信息接入、iframe 的 HttpOnly Cookie 会话、设计与参数化预览页面，以及 Vite、Nginx 和原有 API 网关代理兼容。

## A4 导出问题与处理

- jsPDF 默认字体不包含中文字形，直接生成 PDF 会出现乱码，因此改为调用浏览器原生打印能力。
- 为打印场景单独隐藏页面标题区、桌面导航和移动端底部菜单，只保留白底简历正文。
- 全站新增页脚后，将 `body > footer` 同步加入打印隐藏规则，避免主题、建设日志和 GitHub 链接出现在简历 PDF 底部。
- 删除不适合当前简历定位的“职业概述”，让首屏直接进入工作经历。
- 清理重复的 `@media print` 规则，取消对整段技能区和项目区的强制不分页，减少第一页底部大面积留白。
- 设置 A4 纵向纸张、打印边距、字号、行高及条目级防断页规则，使内容自然排布为两页左右。

## 验证

执行 Astro 生产构建，87 个静态页面生成成功。浏览器打印预览需要在修改后关闭旧预览并刷新页面，才能载入最新打印样式。

## 首页文案调整

原首页使用“WYT 技术博客”和“个人技术博客 · 在线简历 · 项目作品集 · 建设日志（Astro + Vue + Tailwind）”描述自己，信息重复且更像建站模板介绍。调整后使用克制的“WYT Notes”作为站点标识，以“从业务现场，到代码实现”作为首页主题，正文自然说明 MES、EAM 项目经历和 AI 应用学习方向；首屏不再罗列建站技术栈，快捷入口也改为阅读文章、查看项目、个人简历和了解我。
