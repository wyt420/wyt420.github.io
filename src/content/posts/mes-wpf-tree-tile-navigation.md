## 需求背景

传统树形菜单适合熟悉层级的用户，磁贴工作台更适合新人和跨模块操作。系统需要允许用户在 Tree 与 Tile 两种模式间切换，同时不影响已经打开的业务页。

## 问题与约束

- 切换模式不仅是隐藏侧栏，还涉及内容区宽度、默认首页和当前 Tab；
- Shell 与工作台属于不同模块，直接互相引用会破坏模块边界；
- 切到磁贴后立即触发菜单导航，容易和 Region 页面切换争抢 UI 线程；
- 模式状态必须在顶栏按钮、侧栏和工作台之间保持一致。

## 方案

定义统一的 `MenuNavigationMode` 状态，并通过 Prism 事件总线发布模式变化。Shell 根据状态控制侧栏和内容区，工作台订阅事件更新选中态。

磁贴点击采用两步处理：先让 Shell 显示内容页面，再在 Dispatcher 空闲优先级触发原菜单点击。这样可以避免布局尚未稳定时同时执行 Region 切换和业务导航。

主题样式集中在资源字典中，Tree 与 Tile 模式复用同一套顶栏、Tab、侧栏视觉变量，避免每个模块单独调整。

## 踩坑

早期把“切换 Tile”与“立即打开工作台”写在同一个同步事件中，偶发出现页面不显示或 Tab 状态不同步。问题本质是多个 UI 动作处在同一个 Dispatcher 周期。拆开状态变更与页面导航后，行为更稳定。

## 验证

- 在已有业务 Tab 打开时反复切换模式；
- 从磁贴打开页面后切回树形，菜单和 Tab 状态一致；
- 不同分辨率下侧栏隐藏后内容区正确铺满；
- 初始化、权限刷新后模式事件不会重复触发导航。

## 项目经历表述

> 为 WPF MES Shell 增加 Tree / Tile 双模式导航，以 Prism EventAggregator 解耦 Shell 与工作台，并通过 Dispatcher 调度解决布局切换和菜单导航的时序冲突。
