## 背景

MES Web 菜单由后端权限接口返回，再动态注册到 Vue Router。新增“应用中心”后，需要把同一批入口变成可搜索的模块磁贴。

## 遇到的问题

如果为应用中心单独维护 JSON，会与后端权限菜单产生偏差；简单把路由拍平成一层又会丢失二、三级业务分组。此外，部分动态路由的菜单 path、route name 与最终注册地址并不完全一致。

## 实现

`useMenuRoutes` 统一读取 permission store 中的路由树，负责首页置顶、单叶子提升和一级菜单排序。`menuFlatten` 再将路由树转换为磁贴分组，保留子分组、直属叶子和面包屑信息。

点击入口时不直接拼接 URL，而是通过 Router 解析候选地址，确认已注册路由后再跳转。应用中心搜索则基于预先生成的标题与 breadcrumb 索引过滤。

为了减少首次切换等待，在鼠标悬停平铺模式按钮时预加载应用中心 chunk，并预热磁贴分组缓存。

## 踩坑

最初切换平铺模式会强制 `push('/app-center')`，造成主布局重渲染和 KeepAlive 页面状态丢失。后来把“导航模式”与“当前路由”分离：切换只改变布局，用户明确点击应用入口时才改变路由。

## 验证

- 使用不同权限账号核对磁贴数量；
- 覆盖二级、三级及单叶子菜单；
- 搜索结果保留正确的业务分组信息；
- 动态路由刷新后缓存同步更新；
- 切换模式不破坏当前业务页状态。

## 项目经历表述

> 基于 Vue Router 权限路由设计 MES 应用中心，动态生成分组磁贴和搜索索引，统一树形菜单与平铺导航的数据源，并处理动态路由解析、缓存预热及 KeepAlive 状态保持问题。
